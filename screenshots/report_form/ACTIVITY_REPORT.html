IT 110 Lab Activity — Report Form with Async UI States

Prenatal Care System (Flutter Web) · Semester Project · Submitted 21 October 2026

Activity summary

For this activity we extended our Prenatal Care System Flutter Web project with a new Submit Report screen (lib/screens/report_form_screen.dart), opened from the File a Report button on the dashboard. The screen contains a validated report form (full name, email, title, concern details, and a report-type chip selector) backed by a simulated ReportService. Submitting the form shows the four asynchronous UI states required by the activity: Loading (full-page centered spinner with “Submitting report…”, matching the reference design), Success (“Report received” with reference RPT-0001), Empty (“No reports yet” in the My-reports panel), and Error (“Could not submit your report” when the Other channel is under maintenance). The screen is registered on route /report and linked from a File a Report button on the dashboard. We verified the behaviour with flutter analyze (no issues) and flutter test (3/3 widget tests passing), then captured the six screenshots below from the running release build and pushed everything to GitHub.
